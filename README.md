# Learn Java 1

A simple Java learning project demonstrating basic operations and OOP concepts.

## Structure

- `src/main/java/com/learn/` - Main Java source files
- `src/test/java/com/learn/` - Test files

## Features

- Basic calculator operations
- String utilities
- More to come...

## Running

```bash
javac src/main/java/com/learn/*.java
java -cp src/main/java com.learn.Main
```
